A deadpan one-star review of an everyday essential for the 'One-Star Review of Something Essential' bounty: **"One star for gravity. It dropped my phone, my toast, and my dignity — all before 9 a.m. Zero refunds, and it happens every single day."** The program writes that single line to /output/entry.txt.

## Run it

```sh
python3 main.py
```
